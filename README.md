# Market Day Talk

고양이 가게 주인 **누리**와 영어로 물건을 사 보며 마켓데이 표현을 연습하는 5살 아이용 대화 놀이입니다.

**바로 하기:** https://archiblueeee-wq.github.io/market-day/

연습하는 표현: Hello! · I want a carrot! · I wanna buy a red flower! · How much is it? · Thank you!

두 가지 모드
- **따라 말하기**: 노란 새가 문장을 먼저 읽어줘요.
- **스스로 말하기**: 문장을 가리고 그림과 우리말 질문만 보여줘요. 한 번 안 들리면 새가 힌트를 줘요.

- 발음이 정확하지 않아도 목소리만 들리면 항상 칭찬하고 넘어가요.
- 소리가 잘 안 잡히면 노란 **말했어요** 버튼을 눌러 주세요.
- 패드/폰에서 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요. 처음 마이크를 누를 때 **허용**을 눌러 주세요.

수정은 `src/market.html`에서 하고 `./build.sh`로 `index.html`을 다시 만듭니다.
